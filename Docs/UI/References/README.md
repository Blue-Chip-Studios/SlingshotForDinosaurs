# UI References

Drop UI reference images here: screenshots of games whose UI you like, mockups, sketches, icon/font inspiration, colour palettes.

- Use PNG or JPG, and name files descriptively (e.g. `shop-panel-cartoony.png`, `hud-currency-example.jpg`).
- Add a line below for anything that needs context (what you like about it, which screen it's for).

BCDK-Build-Game reads this folder in its UI/UX design phase and builds the game's UI design system (typography, buttons, panels, colours, spacing, animation) from these references instead of generating concepts from scratch.

## Notes
- `01-hud-side-buttons-leaderboard-timers.webp`: chunky colour-coded side buttons (Shop/Index) with icon + bold outlined text and a red "!" notification badge; right-side square icon buttons with a live countdown; big outlined title text; currency stack bottom-left; event timer bottom-right.
- `02-hud-bottom-nav-quests-sleek.webp`: a sleeker, flatter direction for contrast: bottom nav bar of icon-over-label tabs with a highlighted primary (Play); daily/weekly quest strip with progress counters and timers across the top; level + XP bar and coin display with "+" buy button top-left.
- `03-new-pet-reveal.webp`: unlock/reveal moment: centred item, big outlined name, earning rate underneath, tilted "NEW!" sticker, sparkles.
- `04-shop-item-cards.png`: shop modal: coloured header bar with red close button, rounded cards with name + rarity, 3D item render, tier label and a price/state button (Equipped grey, affordable orange, unaffordable red).
- `05-limited-offer-bundle-popup.png`: limited-time Robux bundle: warm gradient, "worth X" callout, item row with quantity tags, struck-through old price over a big green buy button.
- `06-hud-top-tabs-side-menu.webp`: top-centre location/teleport tabs as chunky textured signs; left menu stack (Shop/Trade/Pass/Guide), each a different colour; friend-boost line and currency bottom-left.

Overall direction: bright, chunky, high-contrast blocky-Roblox UI with thick dark outlines, bold rounded display font with stroke, colour-coded buttons, playful badges/stickers. Image 02 is the sleeker alternative.
